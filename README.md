# A股市场日级数据清洗工具

A股市场日级数据的获取、清洗和存储工具。

## 功能特性

- **多数据源支持**：通过插件式架构支持多种数据源（当前实现 AkShare）
- **复权处理**：支持前复权（qfq）和后复权（hfq）价格
- **数据清洗**：自动检测和处理异常数据
- **本地存储**：支持 CSV、Parquet、JSON 多种格式
- **可扩展性**：易于添加新的数据源和数据处理规则

## 项目结构


## 安装

```bash
pip install -r requirements.txt
```

## 使用方法

### 基本用法

```bash
cd src

# 获取10只测试股票近5年数据
python main.py \
    --start-date 2021-01-01 \
    --end-date 2026-03-08 \
    --adjust qfq

# 指定股票列表
python main.py --stocks 600000 600036 600519
```

### 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--stocks` | 股票代码列表 | 10只测试股票 |
| `--start-date` | 开始日期 | 2021-01-01 |
| `--end-date` | 结束日期 | 当前日期 |
| `--data-dir` | 数据目录 | data |
| `--adjust` | 复权类型 | qfq |
| `--save-format` | 保存格式 | csv |

## 清洗规则

- 标准化列名和日期格式
- 去除重复数据
- 处理缺失值
- 数据类型转换
- 价格校验（最高价≥最低价、收盘价范围等）
- 成交量校验
